Guitar Store Website

This is a fully responsive Guitar Store website built using HTML and CSS. It features a modern, clean design that works seamlessly on all devices, from mobile phones to desktops.

Features

Fully responsive layout with mobile-first design

Clean, modern UI with smooth navigation

Product showcase with guitar images and descriptions

Interactive buttons and hover effects

Organized sections for easy browsing (e.g., Featured Guitars, Categories)

Designed for a great user experience on all screen sizes

Technologies Used:

HTML5

CSS3 (Flexbox, Grid, Media Queries)
